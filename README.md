# ADHD 外部执行大脑（ADHD Executive Workspace）

> 让计划自动发生，让开始变得简单，让未完成不再成为压力。

一款真正面向「启动困难、容易拖延、决策疲劳」人群的智能日常工作台。它不是效率打卡工具——它替你承担重复规划，你只需要打开「今天」，执行眼前的一件小事。

## ✨ 核心理念

- **减少决策**：SOP 设置一次，系统按星期/日期/循环规则自动安排每天的任务
- **降低启动门槛**：「帮我开始」每次只推荐一件事 + 最小第一步
- **零惩罚设计**：没有逾期、失败、连续打卡中断；任务时间只是参考，不是审判
- **每一天都是新的开始**：昨天未完成的任务留在昨天，今天正常展示新安排

## 🚀 运行方式

```bash
# 安装依赖
npm install

# 开发模式（热更新）
npm run dev          # http://localhost:5173

# 生产构建 + 预览
npm run build
npm run preview      # http://localhost:4173
```

> 注意：构建产物使用 ES Module，需要通过 HTTP 服务访问（如 `npm run preview`、`python3 -m http.server`），不能直接双击 `dist/index.html`。

## 🧩 功能地图

| 模块 | 说明 |
|---|---|
| **本周** | 七列总览（移动端横滑日期 + 单日列表），圆圈一键完成/撤销，无评价性统计 |
| **今天** | 双栏时间轴 TO DO \| TIME \| DONE，无固定时间任务归入「随时可以做」，完成后移到右侧、保留计划时间，再次点击可撤销 |
| **我的 SOP** | 自然语言输入或手动创建；工作日/周末/每日/自定义/每月类型；启用/停用/复制/删除；历史完成记录永不覆盖 |
| **帮我开始** | 每次只推荐一件：置顶 > 临近时间 > 低门槛，配合第一步行动与「换一件」 |
| **低能量模式** | 🌿 一键只显示 ~3 件最容易开始的任务，隐藏≠删除≠跳过，关闭即恢复 |
| **专注模式** | 极简界面 + 可选计时（不计时/2/5/10/25分钟），可暂停/继续/退出，退出≠失败 |
| **快速添加** | 右下角「＋」输入即存，默认单次无时间任务，高级选项可设循环/时长/第一步 |
| **任务详情** | 抽屉编辑：名称/日期/时间/时长/循环/第一步/备注/置顶/低能量优先；「只改这次 / 今天及以后」范围选择；跳过这次、移动日期、按范围删除 |
| **数据备份** | 全量导出/导入 JSON；数据存于本机 IndexedDB，刷新/关浏览器不丢失 |

## 🔁 循环规则引擎

支持：单次 / 每天 / 每周（指定星期）/ 每月（几号、第N个星期几、最后一个星期X）/ 每 N 天·周·月。

边界处理：每月 31 日在无 31 日的月份自动跳过、闰年与跨年正确、按需生成日期范围内的实例、同一模板同一天仅一个实例、模板与每日完成状态完全解耦（今天完成不影响明天的生成）。

## 🗂 项目结构

```
src/
├── types.ts               # 数据模型（SOP / 模板 / 实例 / 偏好 / 低能量状态）
├── db/database.ts         # IndexedDB 持久层（原生封装 + 导出/导入）
├── lib/
│   ├── dateUtils.ts       # 本地日期工具（跨年/闰月/月末安全）
│   ├── recurrence.ts      # 循环规则 + SOP 生效日引擎
│   ├── taskGenerator.ts   # 按需生成每日实例（去重、保留历史）
│   └── sopParser.ts       # 自然语言 SOP 解析（规则驱动、可插拔 AI）
├── store/AppContext.tsx   # 全局状态 + 全部真实交互动作
├── components/            # TaskCircle / Drawer / QuickAdd / HelpMeStart / FocusMode / Settings / SopEditor …
└── pages/                 # WeekView / TodayView / SopView
```

## 📌 已知边界（如实说明）

- 自然语言解析为**规则引擎**（无网络依赖、开箱即用）；`sopParser.ts` 为独立模块，可替换为任意 AI API 实现，不影响其他功能
- 本地存储 ≠ 云端同步：多设备不会自动同步，请在「设置」中定期导出 JSON 备份
- 第一版未内置提醒推送（`notificationsEnabled` 字段已预留）
